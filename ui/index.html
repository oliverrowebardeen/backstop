    How it works

    Search. Check. Then decide.

    Telem's default routing calls several engines before any results exist. Backstop asks one, checks what came back against the goal, and spends another search only on a miss.

    Checker decides

    Reads the top 5 results against the goal.

    • HitA top result states the answer.Goes straight to Verified.
    • ShallowThe right page, a thin snippet.Goes to Read the best page.
    • StaleOn topic, but older than the goal needs.Goes to Retry on the next engine.
    • Wrong entityA similar name, a different thing.Goes to Retry on the next engine.
    • DeadNothing relevant came back.Goes to Retry on the next engine.

    Fails open. If the checker errors or takes over 4 s, the results go back unchecked.

    Rescue on a miss max 2

    Read the best page Tavily Extract with the goal as its query, Telem fetch if that fails, then a re-check. Finance questions: any miss takes this path once (5 chunks), with no new search.

    Each rescue follows the engine that just missed; shown after a Tavily or Perplexity first search (out/rescue_table.json). With the checker's rewritten query; Stale adds published_after. Never the same engine twice.

    Limits. Rescues stop at $0.03 or 12 s per search.

      Developers

      One line to switch.

      BackstopTelem keeps Telem's response shape and adds status, verdict, why, trace, cost and a rank reason on every result. Every other AsyncTelem method passes through.

      Python
      from telem import AsyncTelem
from backstop import BackstopTelem

client = AsyncTelem()
client = BackstopTelem()

resp = await client.search(
    "What was Stripe's valuation in its 2023 round?",
    goal="find the valuation figure",
)
print(resp.status, resp.results[0].url)
