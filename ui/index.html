How it works

Search. Check. Then decide.

Telem's default routing calls several engines before any results exist. Backstop asks one, checks what came back against the goal, and spends another search only on a miss.

search(query, goal)

The agent says what it needs, not only what to type.

Telem sessions

Every run is grouped in one Telem session, so each search and rescue shows up together in the Telem console.

Tavily Extract

When a snippet is thin, Extract reads the page with the goal as its query and hands evidence chunks to the checker.

Exportable audit trail

Every search, check and rescue is recorded as an event. The live race exports the whole trail as JSON.

Telem Monitors

Fact sheets that re-verify themselves: a daily Monitor per field marks a value stale when new evidence disagrees.

Developers

One line to switch.

BackstopTelem keeps Telem's response shape and adds status, verdict, why, trace, cost and a rank reason on every result. Every other AsyncTelem method passes through.

Python
from telem import AsyncTelem
from backstop import BackstopTelem

client = AsyncTelem()
client = BackstopTelem()

resp = await client.search(
    "What was Stripe's valuation in its 2023 round?",
    goal="find the valuation figure",
)
print(resp.status, resp.results[0].url)
